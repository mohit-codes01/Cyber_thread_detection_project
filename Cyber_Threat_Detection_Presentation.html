Why Cyber Threat Detection?
Bridging the gap between explosive network traffic volumes and human analyst limitations

⚠️ The Traditional Security Crisis
  • Packet Overload: Modern enterprise networks process millions of flow records per second, making manual inspection impossible.
  • Static Signature Failures: Legacy firewalls rely on pre-stored hashes and rules, which immediately fail against zero-day and polymorphic attacks.
  • Alert Fatigue: Security Operations Centers (SOC) face thousands of false positives daily, drowning critical intrusion signals.
  • Delayed Response Time: Traditional forensic triage takes hours or days after a breach has already compromised critical infrastructure.
💡 The Proposed AI Solution
  • Behavioral Machine Learning: Learns complex statistical patterns in network flow headers (duration, packet rates, byte sizes, protocol states).
  • Binary Classification: Instantly classifies network activity into Normal (0) or Threat (1).
  • Model Prediction Confidence: Generates probabilistic confidence scores (0% to 100%) for every single network packet record.
  • Unified SOC Interface: Translates low-level network telemetry into actionable executive metrics, donut charts, and downloadable reports.

04. DATA PREPROCESSING
Scikit-learn Automated Preprocessing Pipeline
Ensuring robust data cleaning, missing value imputation, and categorical encoding
05
/ 12
⚙️ Two-Branch ColumnTransformer
  • Column Dropping: Automatically removes non-feature columns ['id', 'attack_cat'] to eliminate data leakage and target contamination.
  • Numerical Feature Pipeline:
    • Applied to all continuous flow metrics (bytes, packets, rates, timers)
    • SimpleImputer(strategy='median'): Resilient against heavy network outliers
  • Categorical Feature Pipeline:
    • Applied to string features: ['proto', 'service', 'state']
    • SimpleImputer(strategy='most_frequent'): Fills nulls
    • OneHotEncoder(handle_unknown='ignore'): Prevents crashes when new unseen protocols appear in live network traffic
💻 Pipeline Architecture Code
# Preprocessing Transformers numeric_pipeline = Pipeline([ ("imputer", SimpleImputer(strategy="median")) ]) categorical_pipeline = Pipeline([ ("imputer", SimpleImputer(strategy="most_frequent")), ("encoder", OneHotEncoder( handle_unknown="ignore", sparse_output=True )) ]) preprocessor = ColumnTransformer([ ("numeric", numeric_pipeline, numerical_features), ("categorical", categorical_pipeline, categorical_features) ]) # Complete Production Pipeline pipeline = Pipeline([ ("preprocessing", preprocessor), ("model", RandomForestClassifier(n_estimators=100)) ])

05. MACHINE LEARNING ENGINE
Random Forest Classifier
Ensemble decision tree architecture tuned for high detection rate and minimum false alarms
06
/ 12
🌲 Why Random Forest?
  • Ensemble Power: Combines 100 decorrelated decision trees using bagging (bootstrap aggregation) to drastically eliminate individual tree variance.
  • Non-Linear Patterns: Effortlessly captures complex non-linear relationships between packet rates, protocols, and attack signatures.
  • High Dimensionality: Handles over 42 input features without suffering from the curse of dimensionality.
⚡ Model Hyperparameters
  • n_estimators = 100: 100 independent decision trees voting concurrently on threat status.
  • class_weight = 'balanced': Automatically adjusts weights inversely proportional to class frequencies, solving intrusion class imbalance.
  • n_jobs = -1: Utilizes all CPU cores for parallelized inference and rapid training.
  • random_state = 42: Ensures deterministic, reproducible training runs across all systems.
📊 Inference Outputs
  • Discrete Prediction:
    pipeline.predict(X)
    Returns 0 = Normal or 1 = Threat.
  • Prediction Confidence:
    pipeline.predict_proba(X)
    Extracts the highest probability class: e.g. 98.40% Confidence.
  • Evaluation Metrics: Precision, Recall, F1-Score, and full Confusion Matrix.
Model Serialization
